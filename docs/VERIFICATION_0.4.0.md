# 0.4.0 验证记录

日期：2026-10-16。正式版本沿用 `0.4.0-alpha.1 / 573f80b` 的业务实现，本次更新版本、发布说明和商店扫描元数据；DBX 宿主源码未修改。

## 已完成

- Alpha 全量验证：Go 66 个顶层测试、含子测试 104 项；Windows race、vet、SDK 测试；前端 17 项、类型检查及构建；包内容、平台架构、校验和与握手。详细边界测试见 [Alpha 历史报告](VERIFICATION_0.4.0-alpha.1.md)。
- 真实 DBX MCP 与合成 Admin：查询、Cron、有限日志、权限撤销、任务/执行器创建修改删除闭环均通过。模拟任务没有执行真实 Java JobHandler。
- 本机重启后 Docker 已恢复，真实 Admin 与 MySQL 健康。本机真实 Admin 使用已保存连接，通过 DBX MCP 完成 `connection_info`、`list_executors`、`list_jobs`，分别返回连接能力、2 个执行器及 57 条任务的分页结果。仅做读取，未修改真实业务任务。
- 宿主白名单校验：仅授权模拟连接时，真实连接被明确拒绝；用户授权真实连接后，同一 MCP 工具调用成功。确认插件授权与宿主白名单分别生效。
- 原生 DBX 工作台可加载，AI 入口能打开当前连接的 Agent 会话；最小上下文与推荐问题已通过桥接测试。

## 正式发布 CI

`CI` 对发布提交在 Windows/Linux 执行前端测试与类型构建、Go race/vet、SDK 测试及各平台包握手；发布工作流在 macOS 再次运行测试并构建、校验六个平台包。GitHub Actions 是该提交的最终 CI 结果来源。

## 验收边界

- 真实 Admin 已验证读取；真实 Java 执行器写操作闭环、真实非管理员及真实 SSH 隧道部署仍未完成。对应边界已由模拟测试覆盖。
- 内置 Agent 的界面入口与上下文已验证，实际模型到工具的执行尚未独立验收。
- 本机桌面版本为 0.6.44 开发客户端；最低 0.6.43 声明依据已发布插件协议。
- 交叉编译、包结构与架构校验不等同于在所有操作系统和架构上完成桌面验收。
- 发布包为未签名候选包；GitHub Release 发布不代表商店已审核或签名。
